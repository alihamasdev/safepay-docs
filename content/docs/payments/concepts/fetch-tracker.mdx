---
title: "Fetch Tracker"
description: "This page explains how to fetch a Tracker to see its state"
---

Fetch details for a payment using the tracker token.

```bash title="Example how to fetch a tracker"
curl --location 'https://sandbox.api.getsafepay.com/reporter/api/v1/payments/track_ac6afa9c-7f8b-4789-b84e-b39e6422bef1'
```
