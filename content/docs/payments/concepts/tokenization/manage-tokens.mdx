You can use our APIs to manage stored payment credentials on behalf of your customers. For example, you can

- Get a list of the shopper's stored payment details
- Retrieve a single payment detail
- Remove stored payment details

## List stored payment details

To see all the payment details sotred for a shopper, make a **GET** [`/customers/v1/{customerToken}/wallet/`](https://apidocs.getsafepay.com/#a0a3b828-4e95-456e-ad6f-dff050d3e3c4) request including:

| Property | Type   | Mandatory | Description                                                            |
| -------- | ------ | --------- | ---------------------------------------------------------------------- |
| limit    | number | Y         | The upper bound on the number of results.                              |
| page     | number | Y         | The offset from which to fetch limit many results. Enables pagination. |

```javascript title="List stored payment details in NodeJS"
const safepay = require("@sfpy/node-core")("SAFEPAY_SECRET_KEY", {
	authType: "secret",
	host: "https://sandbox.api.getsafepay.com", // for live payments use https://api.getsafepay.com
});

try {
	const response = safepay.customers.paymentMethods.list(customerToken, {
		limit: 10,
		offset: 0,
	});
} catch (err) {
	console.log(error);
}
```

## Find payment method

To see a single stored payment method for a shopper, make a **GET** [`/customers/v1/{customerToken}/wallet/{paymentMethodToken}`](https://apidocs.getsafepay.com/#84ed7202-22f1-4131-8324-1ca2d8292992) request.

```javascript title="Find stored payment method in NodeJS"
const safepay = require("@sfpy/node-core")("SAFEPAY_SECRET_KEY", {
	authType: "secret",
	host: "https://sandbox.api.getsafepay.com", // for live payments use https://api.getsafepay.com
});

try {
	const response = safepay.customers.paymentMethods.find(customerToken, paymentMethodToken);
} catch (err) {
	console.log(error);
}
```

The `findPaymentMethod` endpoint will return a response with your customer's stored payment method. For example

## Delete payment details

You can delete a single token by its identifier, which is returned when you create a token. Alternatively, to find all tokens for a given shopper, you can [list stored payment details](/docs/payments/concepts/tokenization/manage-tokens#list-stored-payment-details) and get the id from the relevant item in the `wallets` array.

To delete the token, make a **DELETE** [`/user/customers/v1/{customer}/wallet/{instrument}`](https://apidocs.getsafepay.com/#abca60ca-aa3a-496f-81f6-117aac7bce1f) request including the following parameters:

| Property   | Type   | Mandatory | Description                                                        |
| ---------- | ------ | --------- | ------------------------------------------------------------------ |
| customer   | string | Y         | The token of the customer whose payment method you wish to delete. |
| instrument | string | Y         | The token of the payment method you wish to delete.                |

```javascript title="Delete a payment method in NodeJS"
const safepay = require("@sfpy/node-core")("SAFEPAY_SECRET_KEY", {
	authType: "secret",
	host: "https://sandbox.api.getsafepay.com", // for live payments use https://api.getsafepay.com
});

try {
	const response = safepay.customers.paymentMethods.delete(customerToken, instrumentToken);
} catch (err) {
	console.log(error);
}
```

<Callout type="info">
After you delete payment details stored with Safepay, you must also delete any remaining payment details from your servers.

</Callout>
