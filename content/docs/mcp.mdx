Safepay documentation natively supports the [Model Context Protocol (MCP)](https://modelcontextprotocol.io), allowing AI coding assistants such as Claude Desktop, Claude Code, Cursor, and Windsurf to search, browse, and read our latest documentation directly.

## LLM Context Resources

In addition to the real-time MCP server, we provide machine-readable documentation endpoints adhering to the `/llms.txt` specification:

## MCP Server Endpoint

The Safepay documentation MCP server is hosted at:

```http
https://safepay.alihamas.pk/api/mcp
```

## Connecting Your AI Assistant

Choose your AI development tool below to see the connection configuration:

<Tabs items={["Cursor", "Claude", "Windsurf", "VS Code"]}>

<Tab value="Cursor">

```json
{
	"mcpServers": {
		"safepay-docs": {
			"url": "https://safepay.alihamas.pk/api/mcp"
		}
	}
}
```

</Tab>

<Tab value="Claude">

```bash
claude mcp add --transport sse safepay-docs https://safepay.alihamas.pk/api/mcp
```

</Tab>

<Tab value="Windsurf">

```json
{
	"mcpServers": {
		"safepay-docs": {
			"serverUrl": "https://safepay.alihamas.pk/api/mcp"
		}
	}
}
```

</Tab>

<Tab value="VS Code">

```json
{
	"mcpServers": {
		"safepay-docs": {
			"url": "https://safepay.alihamas.pk/api/mcp"
		}
	}
}
```

</Tab>

</Tabs>
