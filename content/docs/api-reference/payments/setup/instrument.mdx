  Create a `tracker` with mode `instrument`. This tracker will save a payment method for future use.

  ### Zero amount authorizations

  For cards, there is an option to save the payment method with a zero amount authorization. To achieve this, add the following to the request body:

  `"is_account_verification": true`

  Note that if this is set then there is no need to perform a reversal as is required in the standard flow.
