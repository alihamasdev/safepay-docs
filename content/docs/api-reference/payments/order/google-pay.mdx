  **Next Actions**

  **FPAN**

  For FPAN transactions, the action response should be passed into Atoms for further processing.

  The transaction flow will then proceed as follows:

  - **Payer Authentication Setup**

  - **Payer Authentication Enrollment**

  - **Authorization** (or Authorization + Capture depending on the configured action chain)

  The merchant should continue processing the transaction based on the action response returned by each step.

  **DPAN**

  For DPAN transactions, no payer authentication steps are required.

  **If do_capture = true:**

  - The transaction will automatically proceed through **Authorization + Capture**.

  - No further actions are required from the merchant.

  **If do_capture = false:**

  - The transaction will stop in the **Authorized** state.

  - The merchant must subsequently either:

    - **Capture** the transaction to settle the funds; or

    - **Reverse** the authorization if the transaction should not be completed.

  The tracker will remain in the Authorized state until one of the above actions is performed.
