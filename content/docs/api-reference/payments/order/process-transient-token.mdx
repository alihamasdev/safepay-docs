title: Process Transient Token
description: |-
  Perform the `PROCESS_TRANSIENT_TOKEN` action. This decodes and processes the provided transient token JWT to setup payer authentication.

  The transient token can be obtained once the customer has entered their card details (PAN, expiry and CVV/CVN). Please refer to the Cybersource [Microform](https://developer.cybersource.com/docs/cybs/en-us/digital-accept-flex/developer/all/rest/digital-accept-flex/microform-integ-v2.html) documentation for details.

  The response for this action yields the card details along with the `payer_authentication_setup` object which carries the `access_token` and the `device_data_collection_url`. These are necessary for collecting the user's device data and passing the resulting fingerprint in the enrollment step.
