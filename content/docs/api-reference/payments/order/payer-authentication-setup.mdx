  Perform the `PAYER_AUTHENTICATION_SETUP` action. This action is the starting point for a tracker that has `raw` or `tms` entry modes. It is the entry point for a payment flow where we setup the 3DS enrollment journey for the customer.

  Explore the example payloads to see how to pass the payment method details for `raw` and `tms` entry modes. For `flex` you may pass an empty body `{}`.

  The response for this action yields the card details along with the `payer_authentication_setup` object which carries the `access_token` and the `device_data_collection_url`. These are necessary for collecting the user's device data and passing the resulting fingerprint in the enrollment step.
